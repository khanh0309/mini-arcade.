# Mini Arcade Football realtime server

Dùng thư mục này làm **Root Directory** khi tạo Render Web Service.

- Runtime: Node
- Build Command: `npm install`
- Start Command: `npm start`
- Environment Variable: `FRONTEND_URL=https://serene-gumdrop-00730c.netlify.app`
- Health check: `/health`

Sau khi Render cấp URL HTTPS, điền URL đó vào `games/arcade-football/config.js` hoặc gửi URL cho ChatGPT để tạo bản V2.5.1 đã gắn sẵn server.
